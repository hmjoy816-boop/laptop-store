# Laptopia – Simple Laptop Store (HTML/CSS/JS)

Pages: `index.html` (home), `products.html` (category/listing), `product.html?id=1` (single product).
Edit products in `js/products.js`. Header/footer are in `renderLayout()` in the same file.

## Run locally
Open `index.html` in a browser.

## Upload to GitHub + free hosting
1. Create a new repository on github.com.
2. Upload all files (keep the `css` and `js` folders) or run:
   git init && git add . && git commit -m "Laptop store"
   git branch -M main
   git remote add origin https://github.com/YOUR-USERNAME/laptop-store.git
   git push -u origin main
3. Repo > Settings > Pages > Source: `main` branch, `/ (root)` > Save.

Photos are hotlinked from Unsplash (free to use). Replace with your own in `js/products.js`.
